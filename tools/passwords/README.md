הכלי מיועד לאחסון סודות **של המשתמש עצמו** (למשל סיסמאות לשירותים עסקיים שהוא מנהל).
אין להשתמש בו כדי לאחסן סיסמאות של לקוחות, עובדים או כל אדם אחר ללא הרשאה מפורשת
ובכתב. כל שימוש כזה עלול לעבור על דיני הגנת הפרטיות וחוק המחשבים.

**הוראות סינון:** יש להריץ את הכלי במחשב מסונן (NetFree / אתרוג / נתיב). המודול

אין לעקוף את הסינון בשום צורה.

## מה זה עושה

המודול מספק שלוש יכולות עיקריות, כולן מקומיות:

| יכולת | פונקציות | מה היא נותנת |
|-------|----------|--------------|
| הצפנה | `gen_key`, `encrypt_text`, `decrypt_text` | הצפנת מחרוזת ב-Fernet (AES-128-CBC + HMAC-SHA256). ההצפנה אקראית — אותו טקסט מוצפן פעמיים נותן שני טוקנים שונים. |
| פיצול סוד | `split_encrypted`, `join_decrypted` | פיצול סוד ל-`n` חלקים, שכל אחד מהם לבדו אינו חושף דבר. שחזור דורש **את כל** החלקים. |
| ערבול סיסמה | `hash_password`, `verify_password` | ערבול ב-PBKDF2-HMAC-SHA256 עם 600,000 איטרציות ומֶלַח אקראי. הסיסמה עצמה לא נשמרת לעולם. |

### על הפיצול — למה XOR ולא חיתוך

חלוקת טקסט לחלקים רצופים ("החלק הראשון הוא החצי הראשון") **אינה מסתירה מידע** —
כל חלק לבדו מכיל קטע קריא מהסוד. הפיצול כאן הוא שיתוף סוד ב-XOR: `n-1` החלקים
הראשונים הם בייטים אקראיים לחלוטין, והחלק האחרון הוא הסוד מוכפל ב-XOR עם כולם.
בלי כל `n` החלקים אין שום דרך לחלץ בייט אחד של הסוד. כל חלק מוצפן בנפרד ב-Fernet.

## דוגמת שימוש

```python
import encryption as enc

# 1. מפתח — חייב להישמר במקום מאובטח (מנגנון המפתחות של מערכת ההפעלה).
#    אובדן המפתח = אובדן כל הנתונים שהוצפנו בו.
key = enc.gen_key()

# 2. הצפנה ופענוח
token = enc.encrypt_text("שם לקוח, 050-1234567", key)
print(enc.decrypt_text(token, key))

# 3. פיצול ל-3 חלקים — שמירה במקומות שונים
parts = enc.split_encrypted("מספר כרטיס: 4580-...", 3, key)
restored = enc.join_decrypted(parts, key, 3)   # הסדר לא משנה

# 4. ערבול סיסמה (הסיסמה עצמה לא נשמרת)
stored = enc.hash_password("הסוד שלי")
assert enc.verify_password("ההסוד שלי", stored)  # False
assert enc.verify_password("הסוד שלי", stored)   # True
```

## פרטי אבטחה

- **מפתח Fernet:** 32 בייטים אקראיים (`secrets`), בקידוד base64. **אין לשמור אותו
  בקוד או ב-git.** אובדן המפתח משמעו אובדן הנתונים.
- **פיצול:** `n-1` חלקים אקראיים + חלק אחרון = XOR של כולם עם הנתון. כל `n` החלקים
  נדרשים. חלק חסר, חלק פגום או מספר חלקים שגוי — נדחים ב-`ValueError`.
- **ערבול סיסמה:** PBKDF2-HMAC-SHA256, 600,000 איטרציות, מֶלַח אקראי של 16 בייטים.
  האימות ב-`hmac.compare_digest` (זמן קבוע) כדי למנוע דליפת מידע בעיתוי.
- **נרמול Unicode (NFC):** סיסמה בעברית או עם תווים מורכבים מזוהה נכון גם אם הוקלדה
  בצורת יוניקוד שונה (`NFC` מול `NFD`) — ראו `test_unicode_normalization_nfc_vs_nfd`.
- **גבולות איטרציות:** ערך מאוחסן עם פחות מ-100,000 או יותר מ-10,000,000 איטרציות
  נפסל, כדי למנוע זמן ריצה ארוך מערך פגום או שהושחת.
- **ערך מאוחסן פגום:** `verify_password` מחזיר `False` ולא זורק חריגה.
