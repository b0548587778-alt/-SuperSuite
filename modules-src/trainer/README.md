# TrainerPro 🏋️

**אפליקציית ניהול מקצועית למאמני כושר** — בנויה כ-PWA. רצה במחשב, נייד ובלי אינטרנט.

נבנתה עבור מאמני כושר, מאמני אומנויות לחימה ויועצי תזונה.

---

## ✨ מה כלול

### 👥 ניהול מתאמנים
- כרטיס מתאמן מלא: פרטים אישיים, מטרות, רמה, מצב רפואי, ציוד זמין
- מחולל תוכניות אימון אוטומטי לפי פרופיל ומטרה
- מעקב אחר אימונים שבוצעו והתקדמות
- גרפים של משקל ומדידות לאורך זמן
- כרטיסיות אישיות: סקירה · תוכנית · תזונה · הערכה · התקדמות · אימונים

### 💪 ספריית תרגילים (62+)
- כל תרגיל כולל: שרירים מעורבים, ציוד, רמה, התוויות נגד
- **הוראות ביצוע מפורטות שלב אחר שלב**
- **טעויות נפוצות וטיפים מקצועיים**
- **וריאציות והסבר אנטומי**
- סינון לפי חלק גוף, ציוד וריצמת קושי

### 🥗 תזונה
- מחשבון BMR / TDEE / יעד קלורי / חלוקת מקרו לפי מטרה
- **מאגר מאכלים ישראלי-כשר** — קוטג׳, פיתה, חומוס, טחינה, חמין, קוגל, מצה, גפילטע, ועוד
- **תפריטים מובנים לדוגמה** כולל יום שבת חרדי
- טיפים תזונתיים מקצועיים
- **לכל מתאמן** — חישוב יעדים אישיים והדפסת תוכנית תזונה אישית

### 🧘 גמישות, יוגה והתאוששות
- שגרות מובנות: בוקר, ערב, הפסקת ישיבה, לפני ריצה, אחרי אימון
- רצפי יוגה: ברכת השמש, יוגת בוקר, יוגה משחזרת
- מדריך התאוששות: שינה, גלילי קצף, מקלחת קרה, עיסוי, נשימה

### 🏃 קרדיו וסיבולת
- מחשבון אזורי דופק (Z1-Z5) לפי גיל
- פרוטוקולי HIIT: טבטה, EMOM, AMRAP, פארטלק
- LISS — קרדיו בעצימות נמוכה
- תוכניות ריצה: מהספה ל-5 ק״מ · הכנה ל-10 ק״מ

### 🥊 אומנויות לחימה
- **אגרוף** — ג׳אב, קרוס, הוק, אפקאט, סליפ
- **קיקבוקס / מואי תאי** — בעיטות, מכות ברך
- **קרב מגע** — מכת כף יד, הגנה מחנק, הגנה עצמית
- **BJJ** — גארד, מאונט, חניקה אחורית
- תרגילי אימון: אגרוף צל, פדים, שק כבד, ספארינג
- כושר ייעודי: מעגלים לאגרוף, מואי תאי, BJJ

### 📚 ידע מקצועי
- 4 פרוטוקולי חימום וקירור מובנים
- 4 פציעות נפוצות עם פעולה מיידית, שיקום ומניעה
- 8 עקרונות אימון מרכזיים
- 5 טכניקות מתקדמות (סופר-סטים, דרופים, רסט-פאוז ועוד)

### 🛠 כלים
- **מחשבון 1RM** עם טבלת אחוזי משקל
- **טיימר אינטרוולים** עם סאונד וגדרות מהירות (טבטה, HIIT, אגרוף, EMOM)
- **הערכה תפקודית (FMS-Lite)** — 5 מבחני תנועה עם שמירת היסטוריה
- **טופס PAR-Q** להדפסה — שאלון בריאות סטנדרטי

### 📤 שיתוף וייצוא
- **PDF מקצועי** — דף שער מעוצב, הוראות ביצוע מפורטות לכל תרגיל, אזהרות רפואיות
- **תוכנית תזונה PDF** — בנפרד, מעוצבת לשליחה למתאמן
- **שיתוף בוואטסאפ** — שלח את התוכנית ישירות למתאמן
- **העתקה ללוח / הורדה כקובץ טקסט**
- **טופס PAR-Q להדפסה ולחתימה**

### 🔒 פרטיות
- **כל הנתונים מקומיים בלבד** — שום דבר לא נשלח לשרת
- אחסון ב-localStorage של הדפדפן
- גיבוי וייבוא דרך JSON
- **עובד גם ללא אינטרנט** (PWA)

## 🚀 התקנה והרצה

### דרישות
- Node.js 18+

### פיתוח מקומי
```bash
npm install
npm run dev
# נפתח ב-http://localhost:5173
```

### בנייה לפרודקשן
```bash
npm run build
# התוצאה ב-dist/
```

## 📦 פריסה (Deployment)

### Netlify (הקלה ביותר)
1. גרור את תיקיית `dist/` לאתר https://app.netlify.com/drop
2. תקבל URL ציבורי תוך שניות
3. שתף עם עצמך / מתאמנים

### Vercel
```bash
npm install -g vercel
vercel --prod
```

### שרת משלך
```bash
cp -r dist/* /var/www/html/
```

## 📱 התקנה כאפליקציה (PWA)

### אנדרואיד (Chrome)
1. כנס לאתר
2. תפריט (3 נקודות) → "התקן אפליקציה" / "Add to Home Screen"
3. האפליקציה תופיע במסך הבית עם אייקון עצמאי

### אייפון (Safari)
1. כנס לאתר ב-Safari
2. כפתור שיתוף → "Add to Home Screen"
3. האפליקציה תופיע במסך הבית

### Windows / Mac (Chrome / Edge)
1. כנס לאתר
2. סמל ההתקנה ⊕ בשורת הכתובת → "התקן"
3. תיפתח כאפליקציה עצמאית בלי שורת דפדפן
